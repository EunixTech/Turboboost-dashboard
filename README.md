# Turboboost Dashboard

1. Introduction:- 

    The TurboBoost Dashboard helps merchants manage the optimization handler and displays analytics on the optimization of various features.

    This means that the dashboard assists merchants in handling optimization tasks and provides them with detailed analytics on how different features are being used to optimize store.

2. Getting Started

Requirements:- 
  - Shopify Account
  - Shop URL

Quick Start Guide:-
  - Step 1: Access the TurboBoost dashboard
  - Step 2: Configure performance optimization settings
  - Step 3: Monitor speed improvements and user experience enhancements

Summary:-

    TurboBoost Dashboard is a tool for all merchants who have installed the TurboBoost app in their Shopify store. It provides merchants all functionality to handle optimization, billing, and all their analytic data in one place.
